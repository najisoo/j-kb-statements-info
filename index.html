macOS 개인용 로컬 명세서 정리 도구

J KB Statements

사용자가 승인한 KB 명세서 메일과 로컬 원본을 정리하고, 거래 행과 금액을 본인의 기존 Google 개인 지출 시트에서 관리하기 위한 도구입니다.

안내 기준일: 2026년 10월 5일

현재 개발·검증 중입니다

무인 예약 실행은 활성화되어 있지 않습니다. 이 사이트는 앱을 설명하는 정보성 페이지이며, 앱 코드나 명세서 원본을 배포하지 않습니다.

결제·송금·금융상품 거래·신용평가를 수행하는 도구가 아닙니다.

어떤 작업을 하나요?

  • 사용자가 승인한 KB 명세서 메일을 읽고, 암호화 HTML 첨부·XLSX 원본을 사용자의 로컬 금융 공간에서 제한된 권한으로 보관합니다.
  • 복호화한 HTML은 메모리에서만 처리합니다.
  • 거래 행과 금융 금액은 본인의 기존 Google 개인 지출 시트로만 전송하여 관리합니다.
  • 메일을 수정·전송·삭제하지 않으며, Google 시트를 생성·삭제하지 않습니다.

Google 연결과 권한 범위

전용 Google OAuth 연결에 Gmail 읽기 전용 권한과 Sheets 권한을 사용합니다. Google 로그인과 동의는 사용자가 Google 화면에서 직접 진행합니다.

Gmail 읽기 전용 권한은 전체 메일을 읽을 수 있는 범위이며, Sheets 권한은 Google 시트를 관리할 수 있는 범위입니다. 프로그램의 사용 목적은 승인된 KB 메일과 사용자의 기존 개인 지출 시트로 한정합니다. Google 권한 자체가 특정 메일이나 한 시트만 접근하도록 물리적으로 차단하는 것은 아닙니다.

연결은 Google 계정의 연결 관리에서 해제할 수 있습니다. 자세한 처리 기준은 개인정보처리방침을 확인해 주세요.

데이터 처리의 경계

금융 내용을 ChatGPT 또는 다른 AI 분석에 보내는 기능은 없습니다. 데이터를 광고에 이용하거나 판매하거나 타인에게 전송하지 않습니다.

인증값은 macOS 로그인 키체인과 private pipe·메모리에서 처리합니다. 로그에는 거래·금액이 없는 처리 상태·건수·해시 등의 실행 메타데이터만 남깁니다. 금융 원문·금액·토큰 등 인증값은 로그에 기록하지 않습니다. 데이터의 보관 기간과 삭제는 사용자가 로컬 원본 위치·Google 시트·키체인에서 각각 직접 관리하며, 자동 영구 삭제는 하지 않습니다.

Google API 데이터는 사용자가 요청하고 동의한 명세서 정리·기존 개인 지출 시트 관리 목적으로만 사용하며, Google API Services User Data Policy의 Limited Use 요건을 따릅니다.

이 공개 사이트에 관하여

이 사이트에는 업로드·로그인·입력 폼·스크립트·쿠키·분석 SDK가 없습니다. 사이트 자체에서 방문자를 추적하지 않습니다. GitHub Pages 호스팅 운영 과정에서는 표준 서버 로그가 처리될 수 있으며, 이는 사이트 자체의 추적 기능과 구분됩니다.

문의는 공개 저장소의 이슈로 남길 수 있습니다. 이슈는 공개되므로 금융 정보·명세서 원본·메일 내용·인증값을 게시하지 마세요.
