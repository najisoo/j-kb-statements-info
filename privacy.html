개인정보처리방침

시행일: 2026년 10월 5일

이 방침은 macOS 개인용 로컬 명세서 정리 도구인 J KB Statements와 그 공개 안내 사이트의 데이터 처리 기준을 설명합니다. 앱은 현재 개발·검증 중이며 무인 예약 실행은 활성화되어 있지 않습니다.

1. 처리 목적

사용자가 요청하고 동의한 KB 명세서 정리와 본인의 기존 Google 개인 지출 시트 관리에 필요한 정보만 해당 목적으로 처리합니다. 결제·송금·금융상품 거래·신용평가를 목적으로 사용하지 않습니다.

2. Google 권한과 실제 사용 범위

전용 Google OAuth 연결에 Gmail 읽기 전용 권한과 Sheets 권한을 사용합니다. 로그인과 동의는 사용자가 Google 화면에서 직접 진행합니다.

Gmail 읽기 전용 권한은 전체 메일을 읽을 수 있는 범위이고, Sheets 권한은 Google 시트를 관리할 수 있는 범위입니다. 프로그램에서는 승인된 KB 메일과 사용자의 기존 개인 지출 시트 처리로 사용 목적을 한정합니다. 이 제한은 프로그램의 처리 기준이며, Google 권한 자체가 특정 메일이나 한 시트만 접근하도록 물리적으로 차단한다는 뜻은 아닙니다.

프로그램은 메일을 수정·전송·삭제하지 않으며 Google 시트를 생성·삭제하지 않습니다.

3. 정보별 처리·보관 위치

  • 암호화 HTML 첨부·XLSX 원본: 해당 사용자의 로컬 금융 공간에서 제한된 권한으로 보관합니다. 이 안내 사이트에 업로드하거나 공개하지 않습니다.
  • 복호화한 HTML: 메모리에서만 처리하며 별도 파일로 보관하지 않습니다.
  • 거래 행·금융 금액: 본인의 기존 Google 개인 지출 시트로만 전송하여 관리합니다.
  • 토큰·인증값: macOS 로그인 키체인에 보관하고, 필요한 처리 과정에서는 private pipe와 메모리를 사용합니다.
  • 실행 로그: 거래·금액이 없는 처리 상태·건수·해시 등의 실행 메타데이터만 기록합니다. 금융 원문·메일 원문·금액·토큰 등 인증값을 로그에 기록하지 않습니다.

4. Google API 데이터의 제한적 사용

J KB Statements의 Google API 데이터 사용과 본인의 Google 시트로의 전송은 Google API Services User Data Policy의 Limited Use 요건을 따릅니다. 사용자가 요청하고 동의한 명세서 정리·기존 개인 지출 시트 관리 목적에 한정하여 사용합니다.

금융 내용을 ChatGPT 또는 다른 AI 분석에 보내는 기능은 없습니다. 데이터를 광고에 이용하거나 판매하거나 타인에게 전송하지 않습니다.

5. 데이터 수명·삭제와 연결 해제

데이터의 보관 기간과 삭제는 사용자가 로컬 원본 위치·Google 시트·macOS 로그인 키체인에서 각각 직접 관리합니다. 프로그램이 이 데이터를 자동으로 영구 삭제하지는 않습니다.

Google 연결은 Google 계정의 연결 관리에서 직접 해제할 수 있습니다. 연결 해제와 이미 보관한 로컬 원본·Google 시트 데이터·키체인 정보의 관리는 별개의 작업입니다.

6. 공개 안내 사이트

이 사이트는 정보성 페이지이며 앱 코드·명세서 원본을 배포하지 않습니다. 업로드·로그인·입력 폼·스크립트·쿠키·분석 SDK를 제공하지 않으며 자체 방문자 추적을 하지 않습니다.

GitHub Pages 호스팅 운영 과정에서 표준 서버 로그가 처리될 수 있습니다. 호스팅의 서버 로그 처리와 이 사이트 자체의 추적 기능은 구분됩니다.

7. 방침 변경

방침 내용이 변경되면 이 페이지를 최신화하여 변경 내용을 안내하고, 새 동의를 받은 뒤 변경된 처리 기준을 적용합니다.

8. 문의

문의는 공개 저장소의 이슈에 남길 수 있습니다. 이슈는 공개되므로 금융 정보·명세서 원본·메일 내용·인증값을 게시하지 마세요.
