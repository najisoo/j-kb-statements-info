이용약관

시행일: 2026년 10월 5일

1. 목적과 제공 범위

J KB Statements는 macOS에서 본인의 KB 명세서를 로컬로 정리하고 기존 Google 개인 지출 시트에서 관리하기 위한 개인용 도구입니다. 이 공개 사이트는 앱 설명과 정책을 안내하며, 앱 코드나 명세서 원본을 배포하지 않습니다.

결제·송금·금융상품 거래·신용평가를 수행하는 도구가 아닙니다.

2. 개발·검증 상태

앱은 현재 개발·검증 중이며 무인 예약 실행은 활성화되어 있지 않습니다. 개발·검증 중인 도구라는 점과 설명·권한·처리 기준을 확인한 뒤 사용해 주세요.

Google 인증의 지속 유지나 토큰의 영구 사용을 보장하지 않습니다. 처리 결과와 시트 반영 내용은 사용자가 원본과 대조하여 직접 확인해 주세요.

3. Google 연결과 사용자 동의

사용자는 전용 Google OAuth 연결 과정에서 Google 로그인과 동의를 직접 진행합니다. 앱은 Gmail 읽기 전용 권한과 Sheets 권한을 사용합니다.

Google 권한은 전체 메일 읽기와 시트 관리가 가능한 범위입니다. 프로그램의 사용 목적은 사용자가 승인한 KB 메일과 본인의 기존 개인 지출 시트에 한정되며, 특정 메일이나 한 시트만 접근하도록 Google 권한 자체가 물리적으로 차단하는 것은 아닙니다.

프로그램은 메일을 수정·전송·삭제하지 않으며 Google 시트를 생성·삭제하지 않습니다.

4. 데이터 사용과 관리

암호화 HTML 첨부·XLSX 원본은 사용자의 로컬 금융 공간에서 제한된 권한으로 보관하고, 복호화한 HTML은 메모리에서만 처리합니다. 거래 행·금융 금액은 본인의 기존 Google 개인 지출 시트로만 전송하여 관리합니다.

토큰·인증값은 macOS 로그인 키체인과 private pipe·메모리에서 처리하며, 로그에는 거래·금액이 없는 처리 상태·건수·해시 등의 실행 메타데이터만 남깁니다. 금융 원문·금액·토큰 등 인증값은 로그에 기록하지 않습니다. 금융 내용을 ChatGPT 또는 다른 AI 분석에 보내는 기능은 없고, 광고 이용·판매·타인 전송도 하지 않습니다.

Google API 데이터는 Google API Services User Data Policy의 Limited Use 요건에 따라 사용자가 요청하고 동의한 명세서 정리·기존 개인 지출 시트 관리 목적으로만 사용합니다. 상세 기준은 개인정보처리방침을 따릅니다.

5. 보관·삭제와 연결 해제

데이터의 보관 기간과 삭제는 사용자가 로컬 원본 위치·Google 시트·macOS 로그인 키체인에서 각각 직접 관리합니다. 앱은 데이터를 자동으로 영구 삭제하지 않습니다.

Google 연결은 Google 계정의 연결 관리에서 해제할 수 있습니다. 연결 해제만으로 기존 로컬 원본·시트 데이터·키체인 정보까지 일괄 삭제되는 것으로 간주하지 않습니다.

6. 공개 사이트와 문의

이 사이트에는 업로드·로그인·입력 폼·스크립트·쿠키·분석 SDK가 없으며 자체 방문자 추적을 하지 않습니다. GitHub Pages 호스팅 운영 과정에서는 표준 서버 로그가 처리될 수 있습니다.

문의는 공개 저장소의 이슈로 남길 수 있습니다. 금융 정보·명세서 원본·메일 내용·인증값을 공개 이슈에 게시하지 마세요.

7. 약관·처리 정책 변경

약관이나 처리 정책 내용이 변경되면 관련 페이지를 최신화하여 변경 내용을 안내하고, 새 동의를 받은 뒤 변경된 기준을 적용합니다.
